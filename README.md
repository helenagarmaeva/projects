# ArbiHunter employer dashboard

Один адаптивный экран работодателя. Ветка `arbihunter-dashboard`.

Запуск: `python3 -m http.server 3000`, затем http://localhost:3000.

- `index.html` — единственная страница.
- `dashboard.css` — дизайн-система, адаптив и hover.
- `dashboard.js` — локальные состояния того же экрана.
- `SOLUTION.md` — все пункты задания, анализ, сценарий, styleguide и UI-kit.

Прототип с вымышленными данными, без backend. Файл Figma не создавался. Существующий опубликованный сайт в `gh-pages` не меняется.
